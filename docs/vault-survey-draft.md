# 宝库使用情况问卷（草稿）

## 开场

我们想了解大家是否使用宝库、怎样寻找资源，以及哪些地方值得改进。无论经常使用、只打开过一次，还是从未听说，都欢迎填写。约需 3 分钟，不需要留下姓名或联系方式。

本问卷用于改进宝库，不评价具体作者或作品。请不要填写个人敏感信息。

## 题目

### 1. 你对宝库的使用情况是？（单选）

- 此前没听说过。
- 听说过，但没打开过。
- 打开过，但近一个月没有使用。
- 近一个月使用过 1–2 次。
- 近一个月使用过 3 次及以上。

前两项跳至第 7 题；其余继续。

### 2. 你通常为什么打开宝库？（多选，最多选 3 项）

- 搜索已经知道名字的资源。
- 按题材或内容类型找适合自己团的资源。
- 看最近有什么新资源。
- 浏览推荐，随便逛逛。
- 看到群内宣传后打开对应资源。
- 投稿或查看自己的作品。
- 其他：____。

### 3. 最近一次寻找资源时，结果如何？（单选）

- 找到了，也实际用于备团或游戏。
- 找到了并阅读或收藏，但还没使用。
- 看到了候选资源，但难以判断是否适合。
- 想找但没找到。
- 没有明确目标，只是浏览。
- 不记得了。

### 4. 使用时遇到过哪些困难？（多选，最多选 3 项）

- 不知道应该搜什么词或选什么标签。
- 搜索结果不够相关，或漏掉了已知资源。
- 看不出资源适用哪套规则。
- 列表太长，难以浏览。
- 新内容不容易看到。
- 简介不足，点开后才发现不适合。
- 链接、加载或手机操作有问题。
- 没遇到明显困难。
- 其他：____。

“没遇到明显困难”与其他选项互斥。

### 5. 浏览某个资源分类时，你更希望默认怎样排序？（单选）

- 最新更新在前。
- 点赞与推荐较高的在前。
- 无所谓，能自行切换即可。
- 不清楚，我很少按分类浏览。

### 7. 哪些方式会让你更愿意发现新资源？（多选，最多选 2 项）

- 在宝库里自己浏览，不需要额外通知。
- 群内定期汇总最近上新。
- 群内偶尔介绍值得关注的资源。
- 邮件订阅上新。
- 群机器人按需搜索资源。
- 都不需要／目前不关注新资源。
- 其他：____。

“都不需要”与其他选项互斥。

### 8. 看到“已收录到宝库”，你通常会怎样理解？（单选）

- 至少经过基本内容检查，但不保证好用。
- 管理组认为值得推荐。
- 没想过／不了解。

### 9. 阅读资源前，你最需要知道什么？（多选，最多选 3 项）

- 是否完整、是否经过实际游玩测试。
- 是否使用 AI，以及用于哪些部分。
- 作者、译者与来源。
- 其他读者的使用反馈。

## 发布与统计建议（不放入问卷正文）

- 公告同时附宝库链接，明确“没用过也欢迎填”，不要只发在核心讨论群。
- 可安排一次全体提醒，但不收集 QQ、邮箱或 IP 来识别受访者；实际问卷平台若自带相关记录，发布前核对设置与告知。
- 问卷保留约一周；具体发布日、截止日待定，不在草稿中虚构日期。
- 统计时将未使用者、偶尔使用者、经常使用者分开，避免把积极发言者等同于所有用户。
- 第 8 题先问现有认知，不在前言先解释“收录不代表推荐”，以免引导回答。
- 不把回复人数当成宝库真实用户总数，也不以问卷多数票替代审核组的责任与执行能力判断。
